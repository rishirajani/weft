# Earlier releases

When a new version of Weft is released, the previous `ontology/weft.ttl` is copied here as
`<version>.ttl` (for example `1.0.ttl`) before the ontology is changed. The build publishes
each file here at `https://w3id.org/weft/<version>`, so version IRIs keep resolving.

Version 1.0 is the current version, so nothing is here yet.
